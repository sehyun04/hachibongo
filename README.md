# hachibongo

키보드·마우스 입력을 따라 책상을 두드리는 하치와레 데스크톱 오버레이. Bongo Cat 방식. 트레이 메뉴에서 치이카와·우사기로 바꿀 수 있다.

- 몸은 치이스페 얼굴 그림(`kasaspace/ui/assets/faces/<캐릭터>.png`)을 손대지 않고 그대로 쓴다. 그 위에 움직이는 발 둘만 그린다.
- 캐릭터마다 다른 것은 그림과 그 그림에서 잰 자리(`src/chars.js`)뿐이다. `scripts/measure-chars.py` 가 그림에서
  팔이 몸에서 나오는 오목한 두 점·눈·입·얼굴색·선 색·실루엣을 재서 만든다. 그 두 점을 하치와레와 같은 자리에 맞춰 앉히므로
  키보드·발·마우스·몸 기울기 계산은 셋이 같이 쓰고, 셋의 머리 크기도 거의 같아진다.
  치이카와는 윤곽선이 갈색이라 그려 붙인 팔·발 외곽선도 갈색이고, 우사기는 팔·발이 크림색이다.
  눌린 키·패드·졸 때의 z 는 캐릭터 색이다(하치와레 귀 파랑, 치이카와 볼 분홍, 우사기 노랑).
  우사기는 귀가 길어 창이 위로 늘어난다(책상은 제자리). 치이카와는 원래 입이 다물려 있어 졸 때도 입은 그대로 둔다.
- 키보드는 하나. 하치 몸 가운데를 기준으로 왼쪽 키는 왼발, 오른쪽 키는 오른발이 누른 키 위에 정확히 내려앉는다.
  눌린 키는 파랗게 켜지며 키캡이 살짝 내려간다. 오른발은 키를 안 칠 때 마우스를 쥐고, 마우스를 만지면 바로 돌아간다.
  마우스는 패드 위에서 커서를 따라 움직이고, 클릭한 버튼·휠이 켜진다.
- 팔은 그림 속 원래 팔 자리(옆구리)에서 나온다. 안쪽 키를 칠 때만 뿌리가 아랫몸 바깥쪽 안에서 따라 들어와 팔이 길어지지 않는다.
- 몸은 좌우로 최대 4도 기운다. 치는 동안은 치는 키 쪽, 마우스를 움직이면 화면 속 커서 쪽. 키를 누를 때마다 살짝 끄덕인다.
- 몸은 치는 키나 마우스 쪽으로 옆으로도 살짝 쏠린다(왼쪽 8, 오른쪽 20까지). 키보드·마우스 범위를 넓혀도 팔이 혼자 늘어나지 않게 나눠 맡는다.
- 책상·키보드·마우스 패드는 한 바닥 위에 있어 같은 소실점으로 뒤가 좁아지고(`main.js` 의 `FLOOR`), 뒤쪽 줄은 세로로도 짧아진다.
  마우스도 패드 뒤로 가면 작아진다. 키보드·패드는 앞면 두께가 있다. 키보드·패드·마우스·발 아래에 그림자가 있고,
  발 그림자는 발이 들리면 커지고 옅어진다. 하치는 원작이 평면 그림이라 음영을 넣지 않는다.
- 꼬리는 하치와레만 있다. 치이카와·우사기 꼬리는 짧아서 책상 아래 몸에 붙은 채 가려진다.
  하치와레 꼬리는 원작대로 통째로 귀와 같은 파랑이고, 팔만큼 굵고 짧으며 끝이 둥글게 살짝 들린다.
  화면엔 머리만 보이고 몸은 책상에 가려 있으니 꼬리도 책상 뒤 마우스 쪽에서 대각선으로 올라와 머리 옆선과 V 자를 이룬다.
  치는 동안은 몸 뒤에서 좌우로 1초에 한 번 왕복하며 살랑살랑 쓸리고(멈추거나 마우스로 넘어가면 서서히 잦아든다),
  클릭하면 한 번 튕기고,
  가만히 있어도 가끔 한 번 흔들고, 졸 때는 바깥으로 쓰러진다.
- 눈은 가끔 깜빡이고, 1분 동안 입력이 없으면 눈 감고 존다.
- 투명한 곳은 클릭이 뒤 창으로 빠진다. 그림을 잡고 끌면 옮겨진다(포커스는 뺏지 않는다).
- 트레이 아이콘 메뉴: 캐릭터(하치와레·치이카와·우사기), 크기(작게·보통·크게), 클릭 통과(고정), 위치 초기화, 종료.
  캐릭터·위치·크기는 `%APPDATA%\com.sehyun.hachibongo\settings.json` 에 남는다.

> 하치와레·치이카와·우사기는 나가노(ちいかわ)의 캐릭터이고 그림의 권리는 원작자에게 있다.
> 이 저장소는 비상업 팬 제작물이다. 판매하거나 수익을 내지 않으며, 권리자가 요청하면 내린다.

## 빌드·실행

Windows 전용이다(전역 키보드·마우스 훅을 Win32 API 로 건다). Node.js 와 Rust 가 있어야 한다.

```
npm install
npm run build          # src-tauri/target/release/hachibongo.exe
npm run dev            # 디버그 실행
```

그림만 볼 때는 `src/index.html` 을 아무 정적 서버로 열면 된다. Tauri 밖에서는 혼자 움직이는
데모가 돌고, `?still` 을 붙이면 멈춘 기본 자세로 뜬다. `?char=chiikawa`·`?char=usagi` 로 캐릭터를 고른다.

치이스페 얼굴 그림이 바뀌면 `python -I scripts/measure-chars.py` 로 다시 잰다(원본 그림이 있는 `../kasaspace` 가 옆에 있어야 한다). 창 높이가 바뀌었다고 나오면
`src-tauri/src/main.rs` 의 `CHARS` 높이도 같이 고친다.

## 구조

| 파일 | 하는 일 |
|---|---|
| `src/index.html` | 장면 전체(인라인 SVG). 몸은 캐릭터 그림, 깜빡임·졸기는 그 위에 눈·입을 덮어 그린다 |
| `src/main.js` | 키 배열, 두 발과 몸 기울기, 표정, 클릭 통과 판정, 캐릭터 바꾸기 |
| `src/chars.js` | 캐릭터마다 그림에서 잰 자리·색. `scripts/measure-chars.py` 가 만든다 |
| `src/<캐릭터>.png` | 치이스페 원본(1254px)을 760px 로 줄인 것. 아이콘은 하치와레로 만든다(`npm run icon`) |
| `src-tauri/src/input.rs` | 전역 키보드·마우스 훅, 커서 60Hz 폴링 |
| `src-tauri/src/main.rs` | 투명 창, 트레이 메뉴, 캐릭터·위치·크기 저장 |
| `scripts/measure-chars.py` | 치이스페 그림에서 캐릭터 자리를 재서 `src/chars.js` 를 만든다 |

## 알아 둘 것

- 관리자 권한으로 뜬 창이 앞에 있으면 그 창의 입력은 보이지 않는다(Windows UIPI). 필요하면 이 앱도 관리자로 실행한다.
- 키를 누른 채 관리자 창으로 넘어가거나 잠금 화면으로 가서 떼는 신호를 놓치면, 1.5초 뒤 실제 키 상태와 대조해 발을 뗀다.
- 어떤 키를 눌렀는지는 발 위치를 고르는 데만 쓰고 저장하지 않는다.
  `HACHIBONGO_LOG=<파일>` 을 주면 5초마다 입력 개수(키·클릭·휠·커서)만 적는다. 훅이 살아 있는지 볼 때 쓴다.
- `HACHIBONGO_CONFIG=<파일>` 로 설정 파일 경로를 바꿀 수 있다.
